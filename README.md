# Basel Purchases — V9.1 (Supabase)

نسخة V9.1 مبنية فوق V9 وتجعل قسم **طلبات جديدة** أسرع لتسجيل ومتابعة الورقيات حتى عندما تكون المعلومات ناقصة جدًا.

## الجديد في V9.1

- جميع حقول **الطلبات الجديدة** اختيارية:
  - الاسم.
  - التفاصيل / البنود كنص حر.
  - الجهة الطالبة.
  - مكان متابعة الورقيات.
  - الصور.
- عند إنشاء الطلب يكفي إدخال **أي معلومة واحدة متوفرة** أو إضافة صورة؛ لا يوجد حقل محدد مطلوب.
- تغيير معنى حقل المكان ليصبح **مكان متابعة الورقيات**، مع المثال:
  - `مكتب الطلبيات - الإدارة العامة`
- الصور لم تعد مطلوبة، ويمكن إنشاء الطلب بدون صورة وإضافتها لاحقًا.
- إذا كانت هناك صورة واحدة فقط، أصبح ممكنًا حذفها أيضًا وترك الطلب بلا صور.
- الكارد الذي لا يحتوي صورة يعرض رمز ورقة بدل فرض صورة.
- الكارد يعرض مكان المتابعة بصيغة **متابعة الورقيات** بدل **المكان**.
- بقي خيار **فتح الكاميرا** إلى جانب اختيار الصور في جميع أماكن إضافة الصور.

## تحسين تحديث الواجهة على الهاتف

تمت إضافة رقم إصدار إلى ملفات CSS وJavaScript داخل `index.html`، مثل:

- `css/style.css?v=9.1.0-20260809`
- `js/app.js?v=9.1.0-20260809`

هذا يمنع متصفح الهاتف من الاستمرار في استخدام نسخة قديمة من ملفات الستايل والجافاسكربت بعد نشر تحديث جديد. عند أي إصدار قادم يفضّل تغيير هذا الرقم مرة أخرى.

## قاعدة البيانات — لمن نفذ V9 سابقًا

نفّذ مرة واحدة في **Supabase SQL Editor** الملف:

`supabase-patch-v7.sql`

أو:

`database/patch-v7-v9-optional-quick-requests.sql`

هذا الـ Patch يزيل شرط أن يكون مكان المتابعة معبأً في الطلب الجديد.

## قاعدة البيانات — تثبيت جديد مباشرة

ملف V9 الأساسي `supabase-patch-v6.sql` تم تحديثه أيضًا بحيث تكون الحقول اختيارية من البداية. إذا كنت على V8 ولم تنفذ V9 أصلًا، يمكنك تشغيل V9 المحدث ثم لا تحتاج V7.

## ملاحظات

- لا يحتاج V9.1 إلى Bucket جديد؛ الصور ما زالت تستخدم `purchase-files`.
- جميع وظائف V8/V9 الأخرى بقيت كما هي.
