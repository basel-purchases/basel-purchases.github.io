# Basel Purchases — V7 (Supabase)

نسخة V7 من نظام إدارة المشتريات المبنية فوق V6.

## الجديد في V7

- تعديل بيانات الطلب من داخل شاشة التفاصيل: النص المختصر، الجهة الطالبة، تاريخ الطلب، الحالة، عدد عروض الأسعار، المورد، السعر النهائي لأمر التشغيل، حالة التصفية، وتفاصيل أمر التشغيل.
- تعديل جميع بيانات بند الشراء بعد إنشاء الطلب: الاسم، المواصفات، المنشأ، الكمية، الوحدة، سعر آخر إدخال، تاريخ آخر إدخال، السعر الفردي، حالة التوفر، الإجراء، والإشارة.
- إضافة بنود جديدة إلى طلب شراء موجود بعد إنشائه.
- إضافة حقل **تاريخ آخر إدخال** لكل بند شراء.
- إعادة حساب السعر الإجمالي للبند والسعر النهائي لطلب الشراء تلقائيًا بعد تعديل أو إضافة بند.
- إضافة صور جديدة على مستوى الطلب نفسه أو أمر التشغيل بعد إنشائه، مع الاحتفاظ بالصور السابقة.
- استمرار دعم الصور المتعددة لكل بند شراء.
- أصبح رفع مرفقات على مستوى الطلب متاحًا أيضًا لطلبات شراء المواد أثناء الإنشاء.

## ترقية قاعدة بيانات V6 إلى V7

نفّذ مرة واحدة في Supabase SQL Editor الملف:

`supabase-patch-v4.sql`

أو نفس الملف داخل:

`database/patch-v4-v7-editing.sql`

الـ Patch يضيف العمود `last_entry_date` ويحدّث دالة إنشاء الطلب لكي تحفظ التاريخ الجديد. صلاحيات V6 الحالية تكفي لتعديل الطلبات والبنود وإضافة المرفقات.

## ملاحظات

- رقم الطلب المولد آليًا ونوع الوثيقة يبقيان ثابتين من شاشة التعديل لحماية العلاقات بين الطلب والبنود والمرفقات.
- في طلبات شراء المواد، السعر النهائي محسوب من مجموع أسعار البنود ولا يعدّل يدويًا.
- يمكن إضافة حتى 8 صور/ملفات في كل دفعة رفع، ويمكن تكرار الرفع لاحقًا.
