# Basel Purchases — V9.2 (Supabase)

نسخة V9.2 مبنية فوق V9.1 وتضيف تحسينات عملية للترتيب وإدخال البنود والأسعار ورقم الإضبارة / الطلب.

## الجديد في V9.2

- نقل زر **إضافة بند جديد** إلى أسفل قائمة البنود:
  - في نموذج إنشاء طلب شراء جديد.
  - داخل تفاصيل طلب شراء موجود.
- عند فتح نموذج إضافة بند داخل طلب موجود، يظهر النموذج نفسه بعد آخر بند في الأسفل، لذلك لا حاجة للرجوع إلى أعلى القائمة.
- جميع حقول الأسعار أصبحت تقبل القيم العشرية مثل:
  - `25.5`
  - `0.3`
- قاعدة البيانات كانت تدعم `numeric` أصلًا؛ التعديل الأساسي في الواجهة هو استخدام `step="any"` ولوحة إدخال عشرية على الهاتف.
- **رقم الإضبارة / الطلب** أصبح نصًا حرًا بدل أرقام فقط، مثل:
  - `171-172`
  - `171/172`
  - `A-17`
  - أو أي صيغة نصية أخرى غير فارغة.
- أضيف زر **↑** إلى كل بطاقة من بطاقات الطلبات الرئيسية، سواء **طلب شراء مواد** أو **أمر تشغيل**.
- ضغطة واحدة على **↑** تنقل الطلب مباشرة إلى أعلى الأولوية وتحفظ الترتيب في Supabase.
- السحب المطول بقي متاحًا للترتيب اليدوي الدقيق.
- تم تغيير رقم نسخة ملفات CSS/JS إلى:
  - `css/style.css?v=9.2.0-20260809`
  - `js/app.js?v=9.2.0-20260809`

## قاعدة البيانات المطلوبة لـ V9.2

إذا كانت قاعدة البيانات الحالية لديك وصلت إلى V9 أو V9.1، نفّذ مرة واحدة في **Supabase SQL Editor**:

`basel-purchases-v9.2-free-request-reference-patch.sql`

أو الملف المكافئ:

`supabase-patch-v8.sql`

هذا الـ Patch يزيل تحقق الأرقام فقط من `request_number`. نوع العمود نفسه كان `text` أصلًا، لذلك لا يوجد تحويل بيانات.

> يبقى رقم الإضبارة / الطلب مطلوبًا وغير فارغ، ويبقى قيد عدم التكرار الحالي كما هو.

## ملاحظات V9.1 المستمرة

- قسم **طلبات جديدة** يبقى مرنًا، وتكفي أي معلومة متوفرة للحفظ.
- صور الطلبات الجديدة اختيارية.
- مكان متابعة الورقيات اختياري.
- فتح الكاميرا موجود إلى جانب اختيار الصور حيث يدعم الهاتف والمتصفح ذلك.
- الصور ما زالت تستخدم Bucket الحالي `purchase-files`.
