# Basel Purchases — V8 (Supabase)

نسخة V8 من نظام إدارة المشتريات المبنية فوق V7.

## الجديد في V8

- عرض **مواصفات البند مباشرة تحت اسم البند** داخل القائمة المختصرة، بدون الحاجة إلى فتح التفاصيل لرؤيتها.
- إضافة زر **حذف الصورة / المرفق** للصور المرتبطة بالطلب أو أمر التشغيل، وكذلك صور البنود.
- بعد حفظ تعديل بند، تعود شاشة التفاصيل تلقائيًا إلى **مكان البند الذي تم تعديله** بدل البقاء أسفل الصفحة.
- رقم الطلب أصبح يُدخل يدويًا عند إنشاء الطلب، ويتكون من **3 أرقام أو أكثر**.
- يمكن تغيير رقم طلب موجود من شاشة **تعديل بيانات الطلب**.
- البحث أصبح يشمل رقم الطلب أيضًا.
- جميع ميزات V7 ما زالت موجودة: تعديل البنود، إضافة بنود، تاريخ آخر إدخال، الصور المتعددة، وتعديل بيانات الطلب.

## ترقية قاعدة بيانات V7 إلى V8

نفّذ مرة واحدة في Supabase SQL Editor الملف:

`supabase-patch-v5.sql`

أو نفس الملف داخل:

`database/patch-v5-v8-request-number.sql`

### ملاحظات رقم الطلب

- الطلبات الجديدة يجب أن يكون رقمها 3 أرقام أو أكثر، مثل `123` أو `1234` أو رقم أطول.
- لا يمكن تكرار نفس الرقم لأن حقل `request_number` فريد في قاعدة البيانات.
- الطلبات القديمة التي تحمل أرقامًا مولدة مثل `REQ-000001` تبقى تعمل كما هي. عند تغيير رقم طلب قديم، يجب إدخال رقم جديد من 3 أرقام أو أكثر.
- لا تشغّل `setup-v2.sql` على قاعدة موجودة؛ استخدم Patch V8 فقط.

## حذف الصور

زر الحذف يطلب تأكيدًا، ثم يحذف الملف من Supabase Storage ويحذف سجل المرفق من قاعدة البيانات. إذا فشل الحذف تظهر رسالة خطأ ويبقى السجل قابلًا لإعادة المحاولة.
